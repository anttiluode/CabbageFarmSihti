What this tests: not whether we can generate a whole new cabbage yet. It tests the division of labour suggested by Sihti G4: slow structure carries layout; residues carry finer content. If a fresh residue looks more coherent only when its local transfer frame is attached to the correct coarse parent, then the missing object is a cross-scale relation rather than another global power spectrum.

Important attacker: the parent-conditioned panel is allowed to keep the real coarse field. That is a scaffold experiment, not object generation. A later gate has to generate the slow core itself. Also, local orientation is hand-designed here; the next scientific step is to measure which parent features actually predict the real residue and learn that transfer rule from data.

v0 spectral field — the baseline that failed on cabbage shape

The original site experiment is retained conceptually: a finite reference can define a stationary 2-D spectral law and fresh random phase can make arbitrarily large fields with matched second-order statistics. That is still useful for granite/cloud-like stationary texture, but phase scrambling showed why it cannot reproduce a structured object such as the cabbage.
