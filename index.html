CabbageFarm tried to encode one continuous world. CabbageFarmSihti asks a different question: can a finite texture tell us the stochastic transfer law that makes fields of that kind, then let fresh coordinate-addressable noise generate new territory forever?

finite reference → transfer law H(kx,ky) → fresh noise → arbitrarily addressed field
192continuous Fourier modes
∞*coordinate domain
0tile seams

This browser page is an illustrative procedural field, not a learned result. The Python code in the repository fits the 2-D spectral law from a real reference image, records a Sihti-style Gaussian residue signature, and then tests whether the simple power-spectrum model is sufficient. If it is not, the next target is cross-octave structure: P(R₂d | R_d).
